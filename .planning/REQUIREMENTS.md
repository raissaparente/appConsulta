# Requirements: appConsulta

**Defined:** 2026-05-14
**Core Value:** Empower hospital employees to quickly and efficiently manage patient appointments and records without complex navigation.

## v1 Requirements

### Authentication

- [ ] **AUTH-01**: User can login with employee ID and password

### Appointments

- [ ] **APPT-01**: User can view a list of today's appointments (Time, Patient, Doctor, Specialty, Status)
- [ ] **APPT-02**: User can tap an appointment to view details
- [ ] **APPT-03**: User can mark an appointment as completed
- [ ] **APPT-04**: User can start a Return Appointment Flow

### Search & Patient Details

- [ ] **SRCH-01**: User can search for a patient by CPF
- [ ] **SRCH-02**: User can view "No patient found" state
- [ ] **SRCH-03**: User can tap "Register New Patient" to open the form
- [ ] **SRCH-04**: User can view patient summary card if found
- [ ] **SRCH-05**: User can view Patient Details (Personal info + Appointment history)

### Registration

- [ ] **REG-01**: User can register a new patient (Name, CPF, Birth Date, Phone, Address)

### Appointment Flows

- [ ] **FLOW-01**: User can select Specialty (New flow only)
- [ ] **FLOW-02**: User can select Doctor (New flow only)
- [ ] **FLOW-03**: User can select Date and Time via Calendar (30-min slots)
- [ ] **FLOW-04**: User can confirm appointment details and save

### Profile

- [ ] **PROF-01**: User can view employee name
- [ ] **PROF-02**: User can view "My Data"
- [ ] **PROF-03**: User can change password

## Out of Scope

| Feature | Reason |
|---------|--------|
| Real-time push notifications | Too complex for beginner MVP |
| Patient-facing app | App is strictly for hospital employees |
